Claude Counter

Traffic recording (for analysis)

Records what claude.ai and its server exchange (requests, response streams, usage limits) so the new interface can be analysed. It is off by default and the recording stays in this browser until you download it. Changes apply to open claude.ai tabs immediately; a recording starts when the setting is switched on.

Masking replaces text with the letter x (same length) and keeps numbers, ids and the structure of the messages. Conversation ids in page addresses are always replaced by :id. Masking is a best-effort heuristic, so look at the file before you share it. With masking switched off the recording contains your messages and the replies.

Limits: about 2.5 MB and 2000 records per page load, the newest 3 page loads are kept. When you delete the recordings, open tabs stop recording; reload a tab to start a new recording.
